
# TASK 2: NUMPY ARRAYS AND NUMERICAL COMPUTATION

## 1. Introduction
This task demonstrates how NumPy arrays are used to store and process numerical data efficiently.

## 2. Objective
To calculate temperature statistics and convert temperature readings from Celsius to Fahrenheit using NumPy.

## 3. Input Values
The program uses 24 hourly temperature readings measured in degrees Celsius.

## 4. Mathematical Operations
- Mean: calculates the average temperature.
- Minimum: identifies the lowest temperature.
- Maximum: identifies the highest temperature.
- Fahrenheit conversion: F = 1.8C + 32.

## 5. Implementation
The NumPy library is imported and the temperature readings are stored in an array. NumPy functions calculate the mean, minimum and maximum values. Vectorized operations convert all readings to Fahrenheit.

## 6. Output Interpretation
The output displays the average, minimum and maximum daily temperatures and the first six Fahrenheit readings. These results help describe the daily temperature pattern.

## 7. Changing an Input Parameter
The program increases every temperature reading by 2°C. The new average also increases by 2°C. This demonstrates how changing input values affects the result.

## 8. Related Real-World Application
The same method can be used by a weather monitoring station to process hourly temperature readings and generate daily summaries.

## 9. Conclusion
NumPy arrays make numerical computation easier and more efficient. The task demonstrates statistical calculations and vectorized temperature conversion.
