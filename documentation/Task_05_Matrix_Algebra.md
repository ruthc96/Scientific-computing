
# TASK 5: MATRIX ALGEBRA AND MATRIX OPERATIONS

## 1. Introduction
Matrices are rectangular arrangements of numbers used in scientific computing.

## 2. Objective
To perform matrix addition, multiplication, determinant calculation and matrix inversion using NumPy.

## 3. Input Values
Matrix A = [[1, 2], [3, 4]]
Matrix B = [[5, 6], [7, 8]]

## 4. Mathematical Operations
- Matrix addition: A + B
- Matrix multiplication: A × B
- Determinant: det(A)
- Matrix inverse: A⁻¹

## 5. Implementation
NumPy arrays are used to represent the matrices. NumPy functions perform the calculations.

## 6. Output Interpretation
The program displays the sum and product of the matrices, the determinant and the inverse of matrix A.

## 7. Changing an Input Parameter
The first element of matrix A is changed from 1 to 2. This changes the matrix multiplication result.

## 8. Related Real-World Application
Matrix operations are used in computer graphics to rotate, scale and transform objects. They are also used in engineering and machine learning.

## 9. Conclusion
NumPy simplifies matrix calculations and makes mathematical operations efficient.
