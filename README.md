
# BIT 2118 - Scientific Computing

## Project Overview
This repository contains the group coursework for BIT 2118 - Scientific Computing.

The project focuses on applying scientific computing concepts and numerical methods using Python to solve mathematical and real-world problems.

## Project Objectives
- Apply scientific computing concepts using Python.
- Implement mathematical and numerical methods.
- Analyse program outputs.
- Modify input values and observe changes in results.
- Apply scientific computing techniques to real-world problems.

## Repository Structure

- `code/` - Contains Python source code for the tasks.
- `documentation/` - Contains explanations and documentation for each task.
- `outputs/` - Contains program outputs, graphs and screenshots.
