# SCIENTIFIC COMPUTING

## BIT 2118 – Scientific Computing Group Work

### Project Overview

This repository contains Python programs, documentation, and output results for the Scientific Computing group assignment.

The project explores numerical and computational methods used to solve mathematical and real-world problems using Python. It includes practical implementations, explanations, parameter variations, and graphical representations of results.

### Project Objectives

- Apply scientific computing concepts using Python.
- Understand and implement numerical methods.
- Solve mathematical problems using computational techniques.
- Analyze and interpret numerical results.
- Visualize results using graphs and plots.
- Explore real-world applications of scientific computing.

### Technologies Used

- Python 3
- NumPy
- SciPy
- Matplotlib

4. Run the required Python task file.
